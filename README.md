# Bluesky bot for Swift

A Swift version of the bot from [Build an Agent](https://atproto.com/guides/bot-tutorial), the atproto tutorial where you write a bot that posts to Bluesky and replies to mentions. It is the Swift counterpart of exercise 8 in the [atproto workshop](https://github.com/nnabeyang/atproto-workshop-ja).

## Branches

| Branch | Contents |
| :--- | :--- |
| `main` | The starting point: log in with an app password. |
| `complete` | The finished bot: post on a schedule, label the account as a bot, and reply to mentions. |

The difference between the two branches is what you build in the exercise.

## Requirements

- Swift 6.4, on macOS or Linux
- A Bluesky account for the bot. Make a new one rather than using your own, so that test posts do not fill your followers' timelines.

On a Mac with Apple Intelligence, the finished bot writes its replies with the on-device model from the Foundation Models framework. Elsewhere it replies with a fortune picked from a fixed list.

## Getting started

```sh
git clone https://github.com/nnabeyang/bsky-bot-swift.git
cd bsky-bot-swift
cp .env.example .env
```

Fill in `.env`, which git ignores:

- `BOT_PDS` — the URL of the bot's PDS, such as `https://example.com`.
- `BOT_HANDLE` — the bot's handle, such as `alice.example.com`.
- `BOT_PASSWORD` — an app password, made in the Bluesky app under Settings > Privacy and security > App passwords. Do not use the account's own password.

Write the values without quotes. Then run the bot:

```sh
swift run bot
```

## Project layout

- `Sources/BskyBotSwift/` — the bot.
  - `PasswordSession.swift` — an XRPC client that logs in with an app password and refreshes its token, like `@atproto/lex-password-session` for the Node.js version.
  - `DotEnv.swift` — reads `.env`, like the `dotenv` package.
  - `Lexicon/` — XRPC methods and records generated by [swift-atproto](https://github.com/nnabeyang/swift-atproto).

### Generating Lexicon code

The Lexicons to generate code for are listed in `.atproto.json`. After changing it, regenerate:

```sh
swift package --disable-experimental-prebuilts plugin \
  --allow-writing-to-package-directory \
  --allow-network-connections all:443 \
  swift-atproto
```

The fetched Lexicons are cached in `.lexicons`. If the generated code looks out of date, delete `.lexicons` and run the command again.
